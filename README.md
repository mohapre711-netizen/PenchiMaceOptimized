# 🛡️ PenchiMaceOptimized+

**Advanced Mace PvP utilities Mod for Minecraft Fabric**  
Built for competitive players who want **speed, precision, and zero delay**.

---

## ⚔️ Overview

**PenchiMaceOptimized+** is a high-performance PvP mod designed to automate critical combat actions like **mace swapping, pearl catching, and elytra handling** — so you can focus on winning fights instead of managing your hotbar.

- ✔ Instant swaps  
- ✔ Smart combat decisions  
- ✔ Fully configurable  
- ✔ Zero lag (event-driven system)

## 🎮 Features

### 🗡️ Smart Mace Swap
- Auto swaps to **Density Mace** while falling  
- Auto swaps to **Breach Mace** when enemy has armor  
- Priority system: **Density > Breach > Normal**  
- Auto revert to original weapon  

---

### 🛡️ Shield Detection
- Detects active shield usage  
- Prevents useless swaps  
- Works from any angle (even top hits)

---

### 🪬 Pearl Catch System
- Detects Ender Pearl throw  
- Switches to **Wind Charge** instantly  
- Auto-use mode + manual mode  
- 5-second catch window  

---

### 🪂 Elytra utilities
- Auto chestplate swap on damage  
- Auto rocket / wind charge selection  
- Glide end weapon swap (Mace / Sword)  

---

### ⚙️ Full Configuration
- In-game config via **ModMenu + Cloth Config**
- Toggle every feature  
- Adjustable delays  
- Keybind support  
- Chat notifications
